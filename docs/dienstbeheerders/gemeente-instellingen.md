# Gemeente-instellingen (DRAFT)

## Overzicht

Als dienstbeheerder kun je de algemene instellingen van je gemeente configureren. Deze instellingen zijn van toepassing op de hele gemeente-omgeving binnen Docleas.

## Toegang tot gemeente-instellingen

1. Log in op de Backoffice-app met je dienstbeheerder-account
2. Navigeer naar **Instellingen** in het hoofdmenu
3. Kies **Gemeente-instellingen**
