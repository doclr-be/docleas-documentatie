# Werkschema (DRAFT)

## Overzicht

Een **werkschema** bepaalt wanneer een agenda beschikbaar is en voor welke producten. Het werkschema is de brug tussen agenda's en producten. Zonder werkschema kunnen burgers geen afspraken maken.
