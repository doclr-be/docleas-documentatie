# Global Header

## Overzicht

De global header is de vaste navigatiebalk die bovenaan elke pagina in je burgerportaal zichtbaar is. Via de header navigeer je snel tussen de verschillende onderdelen van Mijn Burger Profiel en beheer je je accountinstellingen.

## Wat staat er in de global header?

De global header bevat de volgende elementen:

### Logo en naam van het lokaal bestuur

Links in de header zie je het logo en de naam van je lokaal bestuur. Klikken op het logo brengt je terug naar de startpagina van het portaal.

### Navigatiemenu

Via het navigatiemenu bereik je snel de belangrijkste onderdelen:

- **Mijn afspraken** - Overzicht van je aankomende en afgelopen afspraken
- **Afspraak maken** - Start een nieuwe afspraak

### Meldingspictogram

Rechtsboven in de header vind je het meldingspictogram. Een badge geeft aan hoeveel ongelezen notificaties je hebt. Klik op het pictogram om je notificaties te bekijken.

### Profielmenu

Via het profielmenu rechtsboven beheer je je account:

- **Mijn gegevens** - Bekijk en wijzig je persoonlijke gegevens
- **Afmelden** - Log uit uit je burgerportaal
